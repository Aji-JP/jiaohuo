# 叫貨單 jiaohuo

中餐烹調丙級、乙級術科課程用的叫貨單小工具：選好上課日期、題組和份數，自動算出每樣食材要叫多少，產生可以直接貼到 LINE 的叫貨訊息。

每個頁面都是**單一 HTML 檔**，不需要伺服器、帳號或安裝 App，用手機瀏覽器打開就能用；資料只存在那支手機的瀏覽器裡。

| 檔案 | 內容 | 資料存放位置（localStorage） |
|---|---|---|
| `v2.html` | 丙級（301、302 共 24 組）第二版：可排多天，同一天入貨的課會合併成一則訊息；草稿自動保存，紀錄可載入修改 | `jiaohuo.v2`（第一次打開時會自動帶入 `index.html` 的規則、配菜表和紀錄） |
| `yiji.html` | 乙級（201–203 共 15 組），功能和 `v2.html` 相同 | `jiaohuo.yi.v1` |
| `index.html` | 丙級第一版：一次排一天，地點可自由輸入；**草稿不保存**，重新整理就清空 | `jiaohuo.v1` |

## 安裝與開啟

- **放在網站上（建議）**：把這幾個 HTML 檔放到任何靜態網站（例如 GitHub Pages），用手機瀏覽器開網址，再用「加入主畫面」做成捷徑。
- **直接開檔**：把 HTML 檔下載到電腦或手機，用瀏覽器打開即可。

> 資料是跟著「網址＋瀏覽器」存的：同一支手機用 Safari 開和在 LINE 裡點開，資料**不互通**；從檔案開和從網站開也不互通。請固定用同一種方式開。

## 使用方式（`v2.html`／`yiji.html`）

1. **入貨地點**：選中正或仁武。
2. **上課日與課程**：每一天選上課日期，再一堂一堂設定時段（上午／下午）、示範或操作、題組和份數。示範預設 1 份、操作預設 5 份。按「加一天」可以排多天，同一天入貨的課會合併成一張單。
3. 每一天下方會顯示**叫貨日 → 入貨日**（推算方式見下方）。週一、週二上課時，會多問一句「入貨前的那個週日有沒有上課」。
4. **各堂需求與上下午總結**：分堂列出每樣材料每份多少、共多少，上午和下午各做一次加總。
5. **合計叫貨**：
   - 上方切換「全天一起叫／只叫上午／只叫下午」，以及訊息開頭的日期要用入貨日、叫貨日還是上課日。
   - **每次叫貨**：每一行都可以直接改字（改過的會標黃色並保留；之後系統算出的數量變了，會提示「改用新的」）；取消勾選就不叫；「手動加一項」可加清單外的東西。
   - **先查庫存**：每一項都要按「夠」或「要叫」，按「要叫」的才會放進訊息；還沒確認的會在下方提示。
   - **常備調味料**：只列出來提醒，不會放進訊息。
   - 有排課但沒選日期的天數會跳出提醒，這些課不會算進任何一張單。
6. 下方「**複製訊息**」貼到 LINE；「**存到紀錄**」保存這次的訊息和整份草稿。
7. **紀錄**頁：可以「載入修改」（沿用到新日期時，直接改上課日期即可，手動加的項目和改過的字會跟著搬過去）、複製、刪除，以及備份與還原。

`index.html` 的操作大致相同，差別是一次只排一天、庫存品用勾選加入、草稿不會保存。

## 參數說明

### 叫貨日、入貨日怎麼推算

1. 入貨日＝上課前一天；叫貨日＝入貨日前一天。
2. 週一不入貨，提前到週日。
3. 週日只有在「那個週日有上課」（有勾選）時才能收貨，否則再提前到週六。

| 上課日 | 入貨日 | 叫貨日 |
|---|---|---|
| 週三～週日 | 前一天 | 前兩天 |
| 週一 | 週六（週日有課則週日） | 週五（週日有課則週六） |
| 週二 | 週六（週日有課則週日） | 週五（週日有課則週六） |

### 規則頁：每種食材怎麼叫

| 欄位 | 說明 |
|---|---|
| 類別 | **每次叫貨**：放在「每次叫貨」區；**先查庫存**：放在「先查庫存」區，要確認後才叫 |
| 叫法 | 見下表 |
| LINE 上的名稱 | 訊息裡用的名字，空白＝原名（例：雞胸寫成「G胸」、蒜頭寫成「蒜」） |

| 叫法 | 怎麼算 | 可調參數 | 例子 |
|---|---|---|---|
| 加總後進位 | 所有份數加總後無條件進位到整數 | 單位（可空白）、最少叫多少（填 0＝不限） | 洋蔥每份 1/4 個 × 5 份＝1.25 → `洋蔥✖️2`；四季豆最少 150g |
| 依每份規格列出 | 每份規格不同就分開列，寫成「規格✖️份數」 | — | `大里肌130g✖️5`、`G胸1/2✖️5` |
| 換算成台斤 | 總克數 ÷ 600 g，四捨五入到半斤，最少半斤 | 每 1 個約幾克（本身是 g 填 1）、進位方式（四捨五入／無條件進位） | 蔥每支約 20g、無條件進位；薑本身是 g |
| 整包／整條叫 | 總量 ÷ 每包可供多少，無條件進位 | 每包可供多少、叫貨單位 | 西芹 1 包可供 10 支 → `西芹✖️1包` |
| 固定寫法 | 不管份數，一律寫固定文字 | 固定寫法 | `九層塔✖️30元`、`乾香菇✖️1斤` |

- 數字欄位**清空＝用預設值**；填 0 或負數（「最少叫多少」除外）視為打錯，會改回預設值並提示。
- 「還原這項預設」會清掉這項食材所有自訂設定。
- `v2.html`／`yiji.html` 會把改過的規則標「已自訂」，並提醒到紀錄頁備份。

### 配菜表頁

每個題組的材料（名稱／每份數量／單位）和調味料（空格分開）。發現和紙本不同可在這裡改，改完立即生效；「還原這組」回到內建資料。

### 內建資料格式（改程式時參考）

資料寫在每個 HTML 的 `/*CORE-START*/` 之後：

- `RAW`：`'題組代號': ['菜名1,菜名2,菜名3', '材料 數量 單位|材料 數量 單位|…', '調味料 調味料 …']`。材料名稱不能有空格；丙級的 `@` 會展開成 `G`（紅K、紅辣椒、小黃瓜、大黃瓜各一份）。
- `DR`：每種食材的預設叫法，欄位同規則頁（`c` 類別 `o`/`s`、`t` 叫法 `sum`/`spec`/`jin`/`pack`/`fixed`、`a` 名稱、`u` 單位、`min`、`g`、`r:'up'`、`per`、`f`）。
- `ORDER`（丙級）／`ROWS`（乙級）：叫貨單的排列順序。
- `APP`：備份檔的級別標記（`bing` 丙級、`yi` 乙級），還原時用來擋下另一個級別的備份。

`/*LOGIC-START*/` 到 `/*CORE-END*/` 之間是三個頁面共用的計算邏輯，**三頁必須一字不差**，改一頁就要同步改另外兩頁（測試會檢查）。

## 測試

只測計算邏輯（只需要 Node.js 18 以上，不用裝任何套件）：

```bash
node --test test/core.test.js
```

連同畫面一起測（用 Playwright 開 Chromium 實際操作三個頁面）：

```bash
npm install
```

```bash
npx playwright install chromium
```

```bash
npm test
```

- `test/core.test.js`：叫貨量（各種叫法、1/6 這類分數的進位）、叫貨日推算（含跨月跨年、閏年、錯誤日期）、訊息格式、備份資料清理、級別判斷，以及三頁共用邏輯是否一致。
- `test/ui.test.js`：開頁無錯誤、惡意備份不會執行程式、壞掉的備份或 localStorage 不會讓頁面當掉、另一級別的備份會被擋下、規則數字清空回預設、剪貼簿失敗時的備援複製、改日期後手動項目跟著搬、沒選日期的提醒等。沒裝 Playwright 時會自動略過。
- 推到 GitHub 時，`.github/workflows/test.yml` 會自動跑全部測試。

## 已知限制

- **資料只存在這支手機的這個瀏覽器**：換手機、清除瀏覽資料、用無痕模式都會不見。請定期到紀錄頁「產生備份」，把文字存到 LINE 記事本。
- 同一個網域底下的其他網頁也讀得到這些資料（瀏覽器是以網域區分），不要把這些頁面和來路不明的網頁放在同一個網域。
- 叫貨日推算只考慮「週一不入貨」和「週日要有課才能收貨」，**沒有考慮國定假日、颱風假或店家公休**，遇到時請自己調整。
- 「換算成台斤」預設是四捨五入到半斤，可能比需要的少（例：薑需 400g，只會叫半斤 300g）；要保險就把那項改成「無條件進位」。
- 同一種食材在不同題組用不同單位時（例：丙級的乾木耳有「g」也有「朵」），「加總後進位」會把數字直接相加；目前乾木耳是固定寫法所以不受影響，自己新增材料時請統一單位。
- `v2.html`／`yiji.html` 的入貨地點只有中正、仁武兩個，要新增需改程式裡的 `PLACES` 和按鈕。
- `index.html` 的草稿不保存；改過的字在該項數量改變時會被新算的值取代。
- 乙級題組沒有內建菜名，只顯示題組代號。
- 份數上限 999。
- 有些 App 內建瀏覽器不允許自動複製，會提示改用長按手動複製。
- 備份不含目前正在編輯的草稿（紀錄裡存的草稿會包含）。舊版產生的備份沒有級別標記，只能從裡面的題組代號判斷是不是另一個級別的。
